# Token 用量 + 花费金额（dsh-plugin-inline-cost）

**只给官方「Token 用量」卡片加一行**：官方组件原封不动，点开自带用量条时，卡片末尾会出现一行「花费金额」。

```
Token 用量
本轮用量        202,453,818 tok
缓存命中        97.0%
未缓存输入      6,467,892 tok
缓存读取        195,550,208 tok
缓存写入        0 tok
输出            435,718 tok
花费金额        ≈ ¥12.12          ← 只加这一行
```

## 数据来源与准确性（v0.9）

- **单轮卡片**（点消息底部的「用量 x tok」）：用卡片上这一轮的数字，按当前时段峰谷价估算，金额是「本轮」——标题提示里写明「本轮估算」
- **会话卡片**（点输入框下方「x tok · 缓存命中 y%」）：优先取本机 `dsh-token-mb` 的只读接口 `/token-mb/summary`
  （`{ ok: true, data: { sessions } }`，按会话明细逐次累加、每次按当时峰谷与实际模型计价，和官方账单对得上）。
  用**当前会话标题**（官方面包屑）去匹配记录；匹配不到才退回「最近写入的非子代理会话」，此时可能取错，
  悬停能看到用的到底是哪个会话
- **兜底**：token-mb 不在 / 接口返回异常 → 按卡片显示的数字估算，值前面带 `≈`

## 工作原理（只读观察，零接管）

- 插件**不注册任何官方槽位、不替换任何组件**
- 锚点是官方卡片本身：`div[role="dialog"][aria-label="Token 用量"]`（会话级）与 `[aria-label="本轮用量"]`（单轮级），
  卡片里承载明细的是两列网格 `<dl>`
- 卡片打开后，往这个 `<dl>` 末尾追加 `<dt>花费金额</dt><dd>≈ ¥x</dd>`：列宽、右对齐、字号颜色全部继承官方样式
- 卡片关闭时官方 portal 卸载，追加的两个节点跟着消失；插件另有 MutationObserver + 1.5s 兜底，重渲染也能补回
- 任何异常都静默跳过；**移除插件零残留**，不会影响官方卡片
- 不抢占 `tokenUsage` 投影；唯一的外部请求是 token-mb 的只读 `/summary`

## 计价口径

DeepSeek 官方 CNY / 百万 token 峰谷价（与 `dsh-token-mb` 同口径，2026-09-19 抓取）：

| 模型 | 缓存命中 | 未缓存输入 | 输出 |
| --- | --- | --- | --- |
| deepseek-flash / v4-flash | 0.02（低谷）/ 0.04（高峰） | 1 / 2 | 4 / 8 |
| deepseek-v4-pro | 0.15 / 0.3 | 4.5 / 9 | 13.5 / 27 |

- 高峰：北京时间 **周一至周五 9:00–12:00、14:00–18:00**，其余低谷价
- 按**当前时段**统一估算，允许与官方账单有几分差异

## 安装（必须 ASCII 路径）

**不要直接把中文文件夹路径交给 install_bundle**（pnpm 会把 profile 的 package.json 写成 GBK 乱码，导致 DSH 打不开）。先建 junction：

```bat
mklink /J L:\work\plugins\inline-cost "L:\work\deepseek-harness-plugins\输入框花费金额"
```

再 `plugin_manager install_bundle`，target = `L:\work\plugins\inline-cost`。

## 生效方式

客户端 bundle 在页面加载时构建：**装完/改完刷新一次页面（或重启一次 DSH）**生效。
之后打开/关闭用量卡片，花费金额会自动出现/消失；侧栏/设置里能立刻看到「输入框花费金额」配置页。

## 兼容性

- DeepSeek Harness `>=0.2.1-rc.2 <0.3.0`
- 锚点用官方卡片的 `role="dialog"` + `aria-label`（以及单轮卡片的 `data-turn-usage-details`）；官方改版导致找不到卡片时，插件静默不显示（不影响官方功能）

## 风险与免责（必读）

- 插件按「现状」提供；会话卡片优先取 `dsh-token-mb` 官方会话记录，单轮卡片与兜底路径按卡片数字估算，**可能与官方账单有差异，不能作为对账/报销依据**
- 会话匹配为启发式（先按会话标题，退化为最近写入的非子代理会话），多窗口同时活跃且标题重名时可能取错；tooltip 会显示所用会话明细
- 不接管、不替换官方组件；任何异常静默跳过，不影响官方功能
- 安装路径必须 ASCII junction；客户端改动刷新页面（或重启 DSH）生效
- 详细条款见 [DISCLAIMER.md](../DISCLAIMER.md)；使用即视为同意

- 位置：**设置 → 输入框花费金额 / 更多表情和颜文字**（也出现在插件页的配置里）

- 「显示花费金额」开关只控制本插件是否注入那一行；**不提供关闭任何官方组件的选项**
