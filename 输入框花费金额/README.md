# 输入框花费金额（dsh-plugin-inline-cost）

在 DeepSeek Harness 输入框下方的用量条**正下方**加一行：**缓存命中 / 未缓存输入 / 输出 + 花费金额**。金额是**本会话**的估算值，随对话实时更新，鼠标悬停可看分项金额。

> 数据来源：官方客户端投影 `useProjection('tokenUsage')`，与官方用量条同源，**不扫日志、不额外请求接口**，也不依赖任何第三方插件。

## 效果

```
缓存命中 1.2M   未缓存输入 34.5k   输出 12.3k   花费 ≈ ¥0.0421
```

（悬停显示：缓存命中/未缓存输入的分别金额、峰谷时段、计价口径。）

## 计价口径

DeepSeek 官方 CNY / 百万 token 峰谷价（与 `dsh-token-mb` 同口径，2026-09-19 抓取）：

| 模型 | 缓存命中 | 未缓存输入 | 输出 |
| --- | --- | --- | --- |
| deepseek-flash / v4-flash | 0.02（低谷）/ 0.04（高峰） | 1 / 2 | 4 / 8 |
| deepseek-v4-pro | 0.15 / 0.3 | 4.5 / 9 | 13.5 / 27 |

- 高峰时段：北京时间 **周一至周五 9:00–12:00、14:00–18:00**；其余为低谷价
- 金额为估算，允许与官方账单有几分差异（官方按实际调用时间分档计费，这里按当前时段统一估算）

## 安装

```text
plugin_manager install_bundle，
target = <仓库路径>/输入框花费金额
```

安装后刷新页面（或重启 DSH），输入框下方会多出这一行。

## 兼容性

- DeepSeek Harness `>=0.2.1-rc.2 <0.3.0`
- 扩展点：`conversation.composer.dock`（order 2，紧跟官方用量条）
- 纯客户端插件，Host 半侧为空壳；注册失败只跳过自己，不影响界面

## 已知边界

- 只统计**本会话**；跨天/跨会话历史金额请用 `dsh-token-mb` 或官方 Token 面板
- 只对 DeepSeek 官方路由有意义（第三方中转没有对应 CNY 价格）
- 价格表是内置快照，官方调价后需要更新 `src/client.js` 的 `PRICE`
