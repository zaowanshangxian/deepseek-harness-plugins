# Token 用量 + 花费金额（dsh-plugin-inline-cost）

**只给官方「Token 用量」卡片加一行**：官方组件原封不动，点开自带用量条时，卡片末尾会出现一行「花费金额」。

```
Token 用量
本轮用量        202,453,818 tok
缓存命中        97.0%
未缓存输入      6,467,892 tok
缓存读取        195,550,208 tok
缓存写入        0 tok
输出            435,718 tok
花费金额        ≈ ¥12.12          ← 只加这一行
```

## 数据来源与准确性（v0.6）

- **优先**：本机 `dsh-token-mb` 的会话明细接口 `/token-meter-panel/summary`。它是官方 usage 记录逐次累加、每次调用按当时峰谷与实际模型计价，和官方账单对得上；插件取「最近写入的非子代理会话」作为当前会话的累计金额
- **兜底**：token-mb 不可用时，解析官方卡片上显示的数字，按当前时段 Flash 峰谷价估算（`≈` 值）
- 悬停「花费金额」可同时看到：官方记录明细 + 本轮估算，方便对照

## 工作原理（只读观察，零接管）

- 插件**不注册任何官方槽位、不替换任何组件**
- 监听页面 DOM，等官方「Token 用量」卡片打开后：
  1. 从卡片上直接读官方显示的数字（缓存读取 / 未缓存输入 / 缓存写入 / 输出）
  2. 克隆「输出」行的结构，在它后面插入一行「花费金额」
  3. 卡片关闭时自动删除这一行
- 任何异常都静默跳过；**移除插件零残留**，不会影响官方卡片
- 不抢占 `tokenUsage` 投影、不额外请求接口

## 计价口径

DeepSeek 官方 CNY / 百万 token 峰谷价（与 `dsh-token-mb` 同口径，2026-09-19 抓取）：

| 模型 | 缓存命中 | 未缓存输入 | 输出 |
| --- | --- | --- | --- |
| deepseek-flash / v4-flash | 0.02（低谷）/ 0.04（高峰） | 1 / 2 | 4 / 8 |
| deepseek-v4-pro | 0.15 / 0.3 | 4.5 / 9 | 13.5 / 27 |

- 高峰：北京时间 **周一至周五 9:00–12:00、14:00–18:00**，其余低谷价
- 按**当前时段**统一估算，允许与官方账单有几分差异

## 安装（必须 ASCII 路径）

**不要直接把中文文件夹路径交给 install_bundle**（pnpm 会把 profile 的 package.json 写成 GBK 乱码，导致 DSH 打不开）。先建 junction：

```bat
mklink /J L:\work\plugins\inline-cost "L:\work\deepseek-harness-plugins\输入框花费金额"
```

再 `plugin_manager install_bundle`，target = `L:\work\plugins\inline-cost`。

## 生效方式

客户端 bundle 有缓存：**安装后重启一次 DSH** 生效。之后打开/关闭用量卡片，花费金额会自动出现/消失。

## 兼容性

- DeepSeek Harness `>=0.2.1-rc.2 <0.3.0`
- 只依赖官方卡片上可见的标签文字；官方改版导致找不到卡片时，插件静默不显示（不影响官方功能）

## 风险与免责（必读）

- 插件按「现状」提供；金额优先取 `dsh-token-mb` 官方会话记录，取不到时按卡片数字估算，**可能与官方账单有差异，不能作为对账/报销依据**
- 会话匹配为启发式（最近写入的非子代理会话），多窗口同时活跃时可能取错；tooltip 会显示所用会话明细
- 不接管、不替换官方组件；任何异常静默跳过，不影响官方功能
- 安装路径必须 ASCII junction；客户端改动需重启 DSH 生效
- 详细条款见 [DISCLAIMER.md](../DISCLAIMER.md)；使用即视为同意
