# 更新日志

## 0.8.1

- 修复：客户端漏声明 `exports.inject = ['slots']`，导致插件配置页注册失败（配置页不显示）
- 卡片定位：支持 shadow DOM 深度查找，并加 1.5s 周期兜底
- 配置页新增「定位状态」诊断（是否找到官方用量卡片 / 是否插入花费行）

## 0.8.0

- 去掉右下角悬浮 🐞 按钮；新增**插件配置页**（设置 → 输入框花费金额）
- 配置页选项：「显示花费金额」开关、「启用错误上报」（可手动关闭）、错误列表、复制报告、去 GitHub 提 issue、清空
- 明确：不提供关闭官方组件的选项；所有开关只影响本插件

## 0.6.0

- 「花费金额」优先取 **token-mb 官方会话记录**：卡片打开时请求同源 `/token-meter-panel/summary`，取最近写入的非子代理会话的 `cny`（按每次调用实际峰谷/实际模型计价），显示「本会话累计」，比按当前时段估算更准
- token-mb 未安装/接口不可用时，自动退回解析官方卡片文字的估算（v0.5 行为）
- 悬停同时展示：官方记录明细（缓存命中/未缓存/输出、峰谷分档、无价调用）+ 本轮估算
- 离线 harness 双模式验证：official → `≈ ¥9.99`；fetch 失败 → 估算 `≈ ¥12.12`

## 0.4.0

- **改为纯观察注入**：不再注册/替换任何官方槽位，官方「Token 用量」卡片保持原样
- 卡片打开时在「输出」行后克隆一行「花费金额 ≈ ¥x」，关闭时自动移除
- 数据直接解析官方卡片显示的数字（不抢 tokenUsage 投影、不额外请求）
- 修复卡片识别：排除 `<script>` 等文本容器，按最深匹配定位官方卡片
- 离线 harness 验证通过：`花费金额≈ ¥12.12`、分项悬停提示正常
- 移除 v0.3 的「替换 usage 格子」方案（该方案曾导致 `ui-chat` 启动失败，已废弃）

## 0.3.0（已废弃）

- 替换官方用量格子并自绘弹层（会导致 web boot 时 `@deepseek-ai/dsh-client-ui-chat` 激活失败，勿用）

## 0.1.0（已废弃）
