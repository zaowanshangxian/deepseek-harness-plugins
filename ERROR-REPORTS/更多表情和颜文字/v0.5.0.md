# 更多表情和颜文字 · 已知问题与修复记录（截至 v0.5.0）

> 本文件按版本记录真实发生过的问题；后续版本在 v0.6.0.md 继续。

## 现象 1：18 个 Emoji 显示成方框
- 版本：v0.4.x
- 复现：打开「表情」面板，🫶 🩷 🥹 🫣 🫠 🫂 🫥 🫨 🫡 🧋 🤌 🫰 🫧 等显示空白/方框
- 根因：当前 Windows 字体缺这些码位的字形
- 处理：字形审计（Chromium canvas 像素哈希对比缺失码位）后全部替换为同分类可渲染字符；`tools/check.mjs` 增加字形校验
- 状态：v0.5.0 已修复

## 现象 2：改客户端代码后刷新不生效
- 版本：v0.4.x
- 复现：修改 `lib/client.js` 后刷新页面，界面无变化
- 根因：DSH 客户端模块按包 id 缓存 bundle rev，仅刷新页面不会重新加载
- 处理：升级/改代码后**重启一次 DSH**；开发期可用 `clientModules.rebuilt(id)` 发布新 rev（仍需页面重新加载启动清单）
- 状态：已知限制，写入 README

## 现象 3：安装后 DSH 打不开 / 配置被重置
- 版本：v0.4.x 安装期
- 现象：桌面版启动失败（`readProfileManifest` JSON 解析错误），或进入安全模式后设置、插件全丢
- 根因：把**中文目录路径**交给 `install_bundle`，底层 pnpm 写 profile 的 `package.json` 时把中文转成 GBK 乱码（引号断裂/整文件空白）
- 处理：必须用 ASCII junction 安装（`mklink /J L:\work\plugins\more-emoji "<中文目录>"`）；装完用严格 UTF-8 + JSON 校验 profile；已损坏时用 `package.json.bak-*` 还原
- 状态：已规避，写入 README + 免责声明
