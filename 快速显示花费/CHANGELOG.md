# 更新日志

## 0.9.2

- **会话卡片新增「账户余额」一行**：数据取 `dsh-token-mb` 的开源只读路由 `/token-mb/balance`
  （`{ok,data:{balance_infos:[{currency,total_balance}], total_costs:[{amount}]}}`，MIT，
  [上游仓库](https://github.com/olimc2016/dsh-token-meter-panel)）；悬停显示累计消费与数据来源
- token-mb 里关掉 `showBalance` 时返回 `supported:false` → 不显示余额行，配置页提示「已关闭」
- 配置页「定位状态」下面新增「账户余额」诊断行（区分：未取到 / 被上游关闭 / 具体金额）
- 余额走 60s 缓存，单轮卡片不显示余额（那是「这一轮」的口径）


## 0.9.1

- **改名**：插件名从「输入框花费金额」改为「快速显示花费」（仓库文件夹、设置页标题、locale 同步）。
  包名 `dsh-plugin-inline-cost`、扩展点 id、localStorage 键都**不变**，升级无需迁移
- 英文名改为 `Quick Cost Row`（原 `Inline Session Cost`）


## 0.9.0

- **修复「花费金额」一直不出现**：旧版靠「文本里同时出现 未缓存输入/缓存读取/输出/用量」猜卡片，
  在真实页面里会命中聊天记录里的普通文字元素，于是永远插不进去。现在锚定官方卡片本身：
  `div[role="dialog"][aria-label="Token 用量"]`（会话卡片）和 `[aria-label="本轮用量"]`（单轮卡片），
  往卡片里的 `<dl>` 追加 `<dt>花费金额</dt><dd>≈ ¥x</dd>` —— 两列网格、右对齐、颜色全部继承官方样式。
- **修复 token-mb 官方记录从未取到**：路由是 `/token-mb/summary`（旧代码写的是 `/token-meter-panel/summary`，404），
  返回结构是 `{ ok, data: { sessions } }`（旧代码直接读 `payload.sessions`）。现在两个路由都试，两种结构都兼容。
- 会话卡片按**当前会话标题**（面包屑）匹配 token-mb 记录，匹配不到才退回「最近写入的非子代理会话」；悬停显示所用会话。
- 单轮卡片（`data-turn-usage-details`）只给**本轮估算**，不冒充会话累计。
- **修复配置页仍不注册**：0.8.2 里补了 `settings.section` 注册，但 `exports.apply` 没接 `ctx` 参数，
  注册直接抛 ReferenceError 被 catch 吞掉。现在签名改为 `apply(ctx)`，配置页可见（显示开关/错误上报/定位状态）。
- 配置页「定位状态」细化：区分「会话卡片 / 单轮卡片」。

- 配置页现在包含：「显示花费金额」开关、启用错误上报、错误列表、复制报告、去 GitHub 提 issue、清空、定位状态诊断

## 0.6.0

- 「花费金额」优先取 **token-mb 官方会话记录**：卡片打开时请求同源 `/token-meter-panel/summary`，取最近写入的非子代理会话的 `cny`（按每次调用实际峰谷/实际模型计价），显示「本会话累计」，比按当前时段估算更准
- token-mb 未安装/接口不可用时，自动退回解析官方卡片文字的估算（v0.5 行为）
- 悬停同时展示：官方记录明细（缓存命中/未缓存/输出、峰谷分档、无价调用）+ 本轮估算
- 离线 harness 双模式验证：official → `≈ ¥9.99`；fetch 失败 → 估算 `≈ ¥12.12`
