# 使用说明：快速显示花费

> 面向使用者。装好之后每天怎么用、每个数字是什么意思、在哪里改设置，都在这。
> 架构与代码细节见 [DESIGN.md](./DESIGN.md)；出问题见 [TROUBLESHOOTING.md](./TROUBLESHOOTING.md)。

## 1. 前置条件

| 项 | 要求 | 不满足会怎样 |
| --- | --- | --- |
| DSH | `>=0.2.1-rc.2 <0.3.0`（在 `0.2.1-rc.3` 实测） | 卡片结构对不上时静默不显示 |
| `dsh-token-mb` | 可选，但**强烈建议**装 | 没装时「花费金额」退化成本轮估算；「账户余额」不显示 |

## 2. 装好后先确认三件事（30 秒）

1. **设置 → 快速显示花费** 能打开，标题带版本号（例如 `快速显示花费 v0.9.4`）
   —— 打不开说明客户端 bundle 还是旧的，**重启一次 DSH**
2. 打开任意一个已有用量的会话，点输入框下方那一格 `xx tok · 缓存命中 xx%`
3. 卡片最后两行应该是：

```
花费金额    ≈ ¥0.50      ← 本会话累计
账户余额    ¥49.57       ← DeepSeek 账号剩余
```

看到的两个数字和下面「定位状态」一致就说明一切正常：

```
定位状态：已找到会话卡片，已插入花费行（12:34:56）
账户余额：¥49.57（累计消费 ¥57.20）
```

## 3. 两张卡片，两种口径

| 卡片 | 在哪点 | 花费金额的含义 | 账户余额 |
| --- | --- | --- | --- |
| **会话卡片** | 输入框下方 `60.2M tok · 缓存命中 99.7%` | 这个会话从开始到现在的累计（取 token-mb 的官方记录，按会话标题匹配） | 显示 |
| **单轮卡片** | 某条消息底部 `用量 24.2M tok` | **这一轮**的估算（卡片上本轮 token × 当前时段价） | 显示 |

- 两个数字不一样是正常的：一个是会话累计，一个是单轮
- 前面带 `≈` 表示「记录值或估算值」，**不是官方账单金额**
- 鼠标停在「花费金额」上，会显示这个金额的明细（会话名、调用次数、峰谷拆分、估算基准）
- 鼠标停在「账户余额」上，会显示累计消费与数据来源

## 4. 日常会用到的小事

| 想做什么 | 怎么做 |
| --- | --- |
| 不想看到这两行 | 设置 → 快速显示花费 → 取消「显示「花费金额」行」 |
| 想确认当前是不是最新版 | 设置页标题的版本号 |
| 想知道这个数是怎么算的 | 悬停「花费金额」/「账户余额」 |
| 觉得余额不对 | 先看 token-mb 的 Token 面板（左侧导航 `Token`），两边同源；再点面板上的「官方账单页 ↗」核对 |
| 换会话后数字没变 | 会话卡片按**会话**统计，换会话就会变；余额是账号级，不会变 |

## 5. 数据从哪来（一句话版）

| 数字 | 来源 |
| --- | --- |
| 花费金额（会话卡片） | `dsh-token-mb` 的 `/token-mb/summary`，按会话标题匹配 |
| 花费金额（单轮卡片） | 卡片上本轮 token × 当前时段峰谷价 |
| 账户余额 | `dsh-token-mb` 的 `/token-mb/balance`（它在宿主侧查官方余额接口） |
| 累计消费 | 同上，`total_costs` |

三种情况会看不到余额：没装 token-mb、在 token-mb 设置里关了 `showBalance`、官方余额接口异常。

见 [README「卸载」](../README.md#卸载)。插件不写 DSH 配置文件，卸载后官方卡片原样。
