# 排错：工具税

> 症状 → 原因 → 处理。先看这里，再去 GitHub issue。

## 卡片不出现

| 可能原因 | 怎么确认 | 处理 |
| --- | --- | --- |
| 没装 `dsh-token-mb` | 侧栏有没有「Token」 | 装上它（卡片要挂在这个页面里） |
| 侧栏当前不在「Token」 | 看侧栏高亮项 | 点「Token」，等 1 秒 |
| 插件没加载 | 控制台或 Host 日志有没有 `tool-tax: webServer unavailable` | 重启 DSH；确认 `dsh.profile.bundles` 里有 `dsh-plugin-tool-tax` |
| 页面结构变了（DSH 升级） | 卡片出现在奇怪的地方 / 完全不出现 | 升级插件；见下面「结构变更」 |
| 停用状态 | 插件页里看开关 | 重新启用并重启 |

## 卡片跑到会话页/输入框下面

**已知问题**：0.4.0 用「缓存命中」当 Token 页判据，会话页底部用量条也有这个词 → 误插。

- 0.4.1 起：只认「今日消费 / 账户余额」
- 0.4.2 起：先看**侧栏高亮的项是不是 Token**，文本只做第二道校验

如果 0.4.2+ 还出现：说明侧栏高亮的选择器失效（DSH 改了 class 命名），
请把 `nav[class*="panelList"] [class*="panelActive"]` 的实际结构贴到 issue。

## 数字是 0 / 空表

| 原因 | 处理 |
| --- | --- |
| 窗口内没有会话日志 | 正常；聊几轮就有了 |
| 会话日志路径不对（自定义 `DSH_HOME`） | 确认 `DSH_HOME` 指向你真正在用的数据目录 |
| 缓存是旧的 | 删 `~/.dsh/tool-tax/cache.json`，重启 DSH |
| 会话里只有纯文本对话（没调工具） | 正常；只有 `tool/call` 才计入 |

## 数字和「花费金额」对不上

这是**口径不同**，不是 bug：

- 花费金额 = `dsh-token-mb` 的**会话级**成本；
- 工具账单 = 同一批会话里按 `tool/call` 平摊的**工具级**成本。
- 一次 LLM 请求可调多个工具 → 两边的「次数」不是一个东西；
- 未匹配到 `usage` 的轮次不计价 → 金额会略低几个百分点。

想看总账以花费金额/官方账单为准；想看「谁最贵」看工具账单。

## 打开很慢（超过 2 秒）

| 阶段 | 正常耗时 | 慢的原因 |
| --- | --- | --- |
| 第一次（无缓存） | ~2.3 秒 / 53 个会话 | 会话多、文件大；属正常 |
| 之后 | ~27 毫秒 | 若仍慢，检查缓存文件是否可写 |
| 重启后第一次 | 毫秒级 | Host 启动会预热 |

缓存文件：`~/.dsh/tool-tax/cache.json`。删掉会回到「第一次扫描」。

## 卡片样式与官方不一致

正常情况下它复用官方卡片的边框/字体/圆角（纯 DOM + 内联样式）。
如果在深色主题下颜色不对，请贴主题名与截图——这是样式变量没对上，属可修问题。

## 卸载后还有残留

| 残留 | 处理 |
| --- | --- |
| 卡片还在 | 重启 DSH（插件卸载后页面需要重新加载） |
| `~/.dsh/tool-tax/` | 手动删（只是缓存，删了无影响） |
| `localStorage['tool-tax:last']` | DevTools → Application → Local Storage 删除 |

## 怎么提 issue

带这些信息：

1. 插件版本（插件页或 `package.json`）
2. DSH 版本
3. 侧栏当时高亮的是哪一项
4. 浏览器控制台有没有 `tool-tax` 开头的报错
5. `~/.dsh/tool-tax/cache.json` 是否存在、大小多少（**不要贴内容**，里面是工具名和数字）
