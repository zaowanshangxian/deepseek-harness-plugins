# 快速显示花费 · v0.6.0

## 变更
- 「花费金额」改为**优先读取 token-mb 官方会话记录**（`GET /token-meter-panel/summary`）：
  - 取最近写入的非子代理会话的 `cny`（按每次调用实际峰谷/实际模型计价）
  - token-mb 不可用时自动退回解析官方卡片文字的估算
  - 悬停显示：官方记录明细（缓存命中/未缓存/输出、峰谷分档、无价调用）+ 本轮估算

## 历史问题（本插件）
| 版本 | 问题 | 根因 | 处理 |
| --- | --- | --- | --- |
| 0.1.0 | 与官方统计重复的独立行 | 设计错误 | 废弃 |
| 0.3.0 | 启动时 `dsh-client-ui-chat` 激活失败 → DSH 进安全模式、配置重置 | 复用官方 `usage` 格子 id 替换组件 | 废弃，改纯观察 |
| 0.4.0 | 卡片里不出现金额行 | 克隆行依赖 DOM 层级；`<script>` 文本被误判为卡片 | v0.5 文本解析 + 排除 script/取最深 |
| 0.5.0 | 估算口径跨峰谷会偏 | 按当前时段统一计价 | v0.6 官方记录优先 |

## 已知限制
- 会话匹配为启发式（最近写入、非子代理），多窗口同时活跃时可能取错；tooltip 会显示所用会话明细便于核对
- 依赖 token-mb 接口；未安装时降级估算
- 官方卡片文案大改时可能定位失败（静默不显示，不影响官方功能）
