# 参考项目对照（性格 / 表情频率 / 口癖）

调研日期 2026-10-28 ｜ 目的：给「人格绑定 + 频率 + 口癖」找现成的数据模型与对照物，别自己发明。

## 一、直接可对照的 DSH 项目

| 项目 | 星 | 定位 | 数据结构 | 我们能借鉴的 | 我们不该做的 |
|---|---:|---|---|---|---|
| [Amakurai/dsh-liketavern](https://github.com/Amakurai/dsh-liketavern) | 227 | ST 风格角色扮演前端（角色卡 V1/V2/V3、世界书、EJS 模板、MVU、分支隔离） | **SillyTavern 角色卡**：name / description / personality / scenario / first_mes / mes_example / system_prompt / post_history_instructions / extensions | ① 角色的**标准字段**直接当我们的导入格式；② `personality` → 我们的 `guide`；③ `mes_example` 里反复出现的短句 → 口癖候选；④ 它的 `docs/PROMPT_TEMPLATES.md` 是提示组装的好教材 | 不做世界书、EJS、MVU、分支隔离——那是另一个产品，我们只做表达层 |
| [Loping151/dsh-nekowhale-stickers](https://github.com/Loping151/dsh-nekowhale-stickers) | 74 | 表情包知识库 + 本地出图 | 每张图一条语义（name/emotion/tags/meme/use/dir） | ① `SKILL.md` 里 `<!-- persona -->` 占位，按人格改写描述；② 情绪检索权重（name 6 / tags 5 / emotion 4…） | 不做 322 张图的托管、不做 MCP/QQ 桥接 |
| [MlittleFriend/dsh-character-profiler](https://github.com/MlittleFriend/dsh-character-profiler) | 4 | 从对话里分析角色特质 | 一次 LLM 分析出 profile | 「从历史对话反推性格」这个思路，可做"从我的聊天记录自动生成人格档" | 不引入依赖，只用本地模型 |
| [SillyTavern character card V2 规范](https://github.com/bradennapier/character-cards-v2) | — | 事实标准 | 11 个字段（见上） | 导入/导出兼容 | 不追求 100% 兼容（我们的场景是"表达风格"，不是扮演） |

**结论**：DSH 生态里已经有 227★ 的重型 roleplay 插件（liketavern）。我们**不重复它**，而是做它没覆盖的轻量层：
> liketavern 管"角色怎么演"，我们管"这条回复用什么表情、带什么口癖、多密"。

## 二、频率设计的对照

| 方案 | 做法 | 问题 |
|---|---|---|
| SillyTavern | 没有显式频率字段；靠 `mes_example` 数量 + 提示词描述 | 不可控，全靠模型自觉 |
| 我们 v1（只有 maxPerReply） | 人格档给一个上限 | 用户改不了，除非换人格 |
| **我们 v2（本次）** | 客户端 5 档：`auto / off / 1 / 3 / 6`；口癖 `0 / 2 / 3 / 5 / 8` 条一次 | 显式、可覆盖、不绑人格 |

## 三、性格预设（本次扩到 12 个）

原有 8 个：daughter / sweet / tsundere / sassy / kuudere / colleague / cat / genki
新增 4 个：**oneesan（温柔姐姐） / cool（高冷御姐） / chuuni（中二） / lazy（慵懒）**

每个预设 = 5 个风格参数（可爱/正式/毒舌/亲密/密度）+ 可用大类 + 频率上限 + 禁用分类 + 一句 guide + 默认口癖。
新增人格**不改代码**：设置页的 `customPersonas` 里填 5 个数 + guide 即可（host 会与预设合并，同 id 覆盖）。

## 四、下一步（按价值排序）

1. **导入 SillyTavern 角色卡（JSON）**：读 `personality` → guide、`mes_example` → 口癖候选、`name` → 人格名。一次导入就得到一套人格，比手填快。工作量 ~半天。
2. **从聊天记录生成人格档**：用本地 9B 读你自己的会话，提炼 3–5 个口癖候选（不花云端 token）。
3. **沙箱验收**：频率三档 + 口癖两档跑到真实会话里，核对提示与工具输出。
