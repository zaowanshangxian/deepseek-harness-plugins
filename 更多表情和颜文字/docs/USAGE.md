# 使用说明：更多表情和颜文字

> 面向使用者。面板怎么用、配置项各管什么、模型这边怎么吃到这份内容，都在这。
> 架构与代码细节见 [DESIGN.md](./DESIGN.md)；出问题见 [TROUBLESHOOTING.md](./TROUBLESHOOTING.md)。

## 1. 装好后先确认三件事（30 秒）

1. 输入框左侧出现 **😊**（如果没有：设置 → 更多表情和颜文字 → 看「隐藏表情入口」是否被勾上）
2. 点 😊，面板从输入框上方弹出，5 个页签：**表情 / 颜文字 / 文字表情 / 短句 / 贴纸**
3. 让 Agent 说一句「用 emoji_pack 列一下分类」，能返回 44 个分类就说明 Host 半侧也活着

## 2. 日常用法

| 想做什么 | 怎么做 |
| --- | --- |
| 插一个表情到光标处 | 点输入框 → 点 😊 → 点条目 |
| 点一下直接发出去 | 面板底部开「一键发送」，或 设置 → 通用 → 勾「更多表情和颜文字」 |
| 搜一个 | 面板顶部搜索框（匹配分类名与内容） |
| 发图片贴纸 | 贴纸页 → 点图片 → 作为附件贴进输入框 → 回车发送 |
| 收藏 | 悬停条目点 ☆；⭐ 页签统一查看/取消 |
| 找回刚用过的 | 🕘 页签（最近 40 条） |
| 关掉面板 | `Esc` 或点面板外面 |

## 3. 配置中心（设置 → 更多表情和颜文字）

| 配置项 | 管什么 | 想反悔怎么办 |
| --- | --- | --- |
| 隐藏表情入口 | 勾上后 😊 和面板都不显示，但 `emoji_pack` 照常可用 | 取消勾选 |
| 优先发送常用表情 | 模型需要发表情时优先用你填的「常用」 | 关掉 |
| 允许发送的表情分类 | 只显示/只返回勾选的分类；**全不勾 = 全部允许** | 重新勾 |
| 常用词 / 常用表情 | 你常说的话，面板会多出「常用」页签，模型侧置顶 | 删掉即可 |
| 收藏也参与优先 | 收藏会同步给模型一起加权 | 关掉 |

配置存在 `%USERPROFILE%\.dsh\more-emoji\settings.json`（同一份给面板与工具用，改完立即生效，不用重启）。

## 4. 给模型用（emoji_pack）

模型可以自己调这个工具，你不需要手动做任何事。想手动让它用，就直接说：

```text
用 emoji_pack 找几个猫猫颜文字，放在这句话后面
emoji_pack({ kind: "phrase", query: "夸" })   → 夸夸类短句
emoji_pack({ kind: "art", random: true })     → 随机一组文字表情
```

边界：系统提示里已经写明「一条回复 1-3 个、正式内容不加、用户说别用就停」。
不想让它用，直接跟它说「别用表情」；想彻底限制，就把允许分类全取消。
