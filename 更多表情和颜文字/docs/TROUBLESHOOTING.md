# 排错：更多表情和颜文字

先确认三件事，能定位 90% 的问题：

1. 设置里有没有 **更多表情和颜文字** 这一节（没有 → 客户端 bundle 没加载，看第 1 条）
2. 那一节里 **隐藏表情入口**（插件页里叫「隐藏客户端入口（智能体仍可用）」）是否被勾上（勾上就没有 😊，但 `emoji_pack` 仍然可用，这是设计如此）
3. 改了 `lib/` 之后有没有**刷新页面**（`Ctrl+R`；老版本 DSH 要重启）

## 1. 输入框旁没有 😊 按钮

| 可能 | 确认 | 处理 |
| --- | --- | --- |
| 被配置隐藏 | 设置 → 更多表情和颜文字 → 「隐藏表情入口」（插件页里叫「隐藏客户端入口」）是否勾选 | 取消勾选 |
| 客户端 bundle 未加载 | 设置里根本没有这一节 | 刷新页面；确认 profile `dsh.profile.bundles` 有 `dsh-plugin-more-emoji` |
| 装在中文路径下 | profile `package.json` 里出现乱码 | 用 ASCII junction 重装（见 README 安装） |
| 编辑器改版导致按钮槽位缺失 | 面板可能还在（`conversation.input.overlay`），只有按钮没了 | 提 issue 并附 DSH 版本 |

## 2. 点 😊 没反应 / 面板不出现

- 面板是浮层，先看**输入框上方**——小窗口下可能被挤到顶部之外，最大化窗口再看
- 打开控制台（DSH 桌面版可 `Ctrl+Shift+I`）看是否有 `[more-emoji] … 注册失败`：插件对每个扩展点都有保险丝，
  失败会 `console.warn` 并跳过，不会崩 UI
- 两个窗口同时开着时，只有一个窗口会保留面板状态；刷新另一个后再试

## 3. 点条目没插进输入框

- 文本插入走官方 `inputActions`（`captureInsertion` + `insertText`），要求**输入框获得焦点**：
  先点一下输入框光标位置，再点条目
- 富文本（图片/引用）混排的输入区在个别版本会拒绝插入；退回手动复制（面板条目可选中复制）
- 控制台有 `draftRev` / `captureInsertion` 相关错误 → DSH 的 composer API 变了，提 issue

## 4. 贴纸发不出去 / 变成空白

- 贴纸是把 PNG 合成 `paste` 事件交给编辑器上传，**要求能正常上传附件**（网络/账号额度）
- 首帧空白是旧版本问题（v0.5.0 已修）；若仍空白，刷新页面
- 「一键发送」开启时，贴纸会在上传完成后直接发出；关掉它就会停在输入框等你确认
- 附件上传失败会静默丢弃——去「设置 → 账号与余额」看额度是否正常

## 5. 模型不用表情 / 用了不该用的

- 先看 `emoji_pack` 能不能调通：让它「用 emoji_pack 列一下分类」。报错说明 Host 半侧没加载（重启 DSH）
- 系统提示只是**建议**，模型可能不用；「优先发送常用表情」「收藏也参与优先」是提高权重，不是硬保证
- 想彻底限制：配置里只勾允许的分类，`emoji_pack` 就只返回那些
- 想让模型别说「我发了个贴纸」：`docs/AGENT.md` 里已写明图片贴纸是用户侧行为；改文案见该文件

## 6. 面板里 Emoji 显示成方框

- 是**字体缺字形**，不是插件丢了字符：Windows 上少见，Linux/精简系统常见
- 装一份彩色 emoji 字体（Windows 自带 Segoe UI Emoji 即可）
- 或在配置里取消勾选那些分类，避免误点

## 7. 配置改了不生效

- 客户端配置页保存后会**立刻**更新面板；Host 侧（`emoji_pack`、系统提示）**每次读取都重新读文件**，无需重启
- 如果保存失败（例如配置文件被其他程序占用），面板会有提示；重试或手动编辑
  `%USERPROFILE%\.dsh\more-emoji\settings.json`（JSON，字段有白名单校验，写错字段会被忽略）

## 8. 装完 DSH 打不开

几乎都是 profile 被写坏（中文路径 → pnpm 写 GBK 乱码）：

1. 双击桌面 **`DSH一键恢复.cmd`**（`L:\work\scripts\dsh-profile-recover.ps1`，可 `-DryRun` 预演）
2. 或手动用 `package.json.bak*` 覆盖，确认 JSON 合法
3. 重装时用 ASCII junction

## 9. 提 issue 时请带上

- 设置 → 更多表情和颜文字 → **复制报告**（插件版本、UA、最近错误）
- DSH 版本（`dsh --version` 或 设置 → 账号与余额 底部）
- 面板截图 / 控制台截图
- 复现步骤（哪个页签、哪个分类、点了什么）
