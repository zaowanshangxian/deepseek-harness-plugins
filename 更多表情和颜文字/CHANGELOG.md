# Changelog

## 0.4.0 — 配置中心 + 常用词权重

- 新增配置页（设置 → 更多表情和颜文字，同时出现在插件页）：隐藏客户端面板 / 优先发送常用表情 / 允许发送的表情分类（44 分类勾选）/ 常用词与常用表情增删
- 配置存 `DSH_HOME/more-emoji/settings.json`，Host 与客户端共用一份；新增 `/more-emoji/api/settings` JSON API
- `emoji_pack` 遵循配置：只返回允许的分类，并把常用词置顶；系统提示注入动态「用户配置」段落（允许分类 + 常用清单 + 优先要求）
- 面板新增「常用」页签、按允许分类过滤；常规页签仍保留全部内容开关
- 一键发送、收藏、最近使用、图片贴纸保持

## 0.3.0 — 贴纸 / 收藏 / 最近 / 一键发送

- **图片贴纸**：36 张内置 PNG（18 张颜文字 + 18 张文字），点贴纸把图片合成 `paste` 事件交给 DSH 上传为附件，可直接发送
- **一键发送**：设置 → 通用 新增「更多表情和颜文字」勾选项，面板底部也有迷你开关；开启后点条目即发送（走 composer 官方 `submit()`）
- **收藏**：条目悬停点 ☆ 收藏，⭐ 页签统一管理（localStorage 持久化）
- **最近使用**：自动记录最近 40 条，🕘 页签查看
- **插入链路改用官方 API**：`captureInsertion()` + `insertText(text, token)`，不再依赖 DOM 模拟（DOM 保留兜底）
- **给智能体的说明**：Host 注入 `systemPrompt.section`，说明 `emoji_pack` 用法与使用边界；全文见 `docs/AGENT.md`
- 面板 5 页签（新增贴纸）、搜索、随机一发、Esc 关闭保持
- 构建内联贴纸 base64；新增 `tools/make-stickers.py` 可复现生成贴纸

## 0.2.0 — 首个公开版本

- 表情面板：输入框左侧 😊 按钮 + 浮层面板（4 页签 / 44 分类 / 911 条）
- 点击插入光标处、搜索过滤、随机一发、`Esc` / 点外部关闭
- 面板锚定输入框顶部，按可用高度自适应，不遮挡输入内容
- 主题跟随 DSH 的 `--dsw-alias-*` 变量，深浅色自动适配
- `emoji_pack` Host 工具：目录 / 大类 / 分类 / 关键词 / 随机取样
- 内容库单一数据源 `src/packs.mjs`，构建内联进 Client 半侧
- `tools/check.mjs` 校验分类 id、重复条目、坏字符
- 只有文本类表情；无第三方运行时依赖、无网络请求
